# Required Information when Submitting Tank Game

## Version of Java Used: 24

## IDE used: IntelliJ IDEA

## Steps to Import project into IDE: 
1. Open the project folder in the IntelliJ
2. Set the project JDK to the required Java version (24)
3. Allow IntelliJ to load dependencies and project files
4. Run the Launcher class to start the game
   
## Steps to Build Your Project:
1. Open the project in IntelliJ
2. Build the project using the Build option
3. Create the executable .jar file
4. Copy the .jar file into the 'jar' folder
5. Make sure the 'jar' folder only contains the built jar file
  
## Steps to run your Project:
Option 1:
1. Open the 'jar' folder
2. Run the '.jar' file

Option 2:
1. Open a terminal in the 'jar' folder
2. Run: java -jar TankGame.jar
